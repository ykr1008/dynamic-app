DocumentFragment allows multiple DOM elements to be created and assembled in a temporary container before being inserted into the document. In this test, appending 5,000 elements individually took 11.70 ms, while using DocumentFragment took 8.90 ms. The fragment approach was 2.80 ms faster in this run. It can reduce repeated interactions with the live DOM, although the performance benefit depends on the browser and the work being performed. This experiment shows how measuring execution time with performance.now() helps compare different DOM-rendering techniques instead of assuming one is always faster.

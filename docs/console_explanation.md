This experiment demonstrates that CORS is enforced by the browser, not by JavaScript itself. My application requested https://example.com/ using fetch(), and the server returned HTTP 200 (OK). However, its response did not include the Access-Control-Allow-Origin header, so the browser blocked my JavaScript from accessing the response. When I opened the same URL directly in a browser tab, the webpage loaded successfully because direct navigation does not require the same CORS permission. This shows that a server can respond successfully while browser security prevents a cross-origin script from reading the response. CORS errors are browser-enforced security restrictions.
